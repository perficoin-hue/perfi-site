# PERFI SITE

This repository contains the initial Next.js + TypeScript starter for the Perfitech Global Venture Limited corporate website and PERFI SITE builder preview.

Run locally:

1. npm install
2. npm run dev

What I created in this commit:
- A responsive Next.js app with Tailwind CSS
- Company-branded colours (navy and gold)
- Pages: Home, About, Services, PerfiPay, Builder (with AI and Manual placeholders)
- Header and Footer components
